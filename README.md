# PatriaSoul

Hrvatska. Povijest. Znanje. Identitet.

Novi, čisto organizirani PatriaSoul portal. Portal, članci i Hrvatski kviz žive u jednom GitHub Pages projektu.

## Struktura

- `stranice/` — stalne stranice portala
- `kategorije/` — stranice kategorija
- `clanci/` — članci po kategorijama
- `kviz/` — Hrvatski kviz
- `cuvari-nasljedja/` — Čuvari nasljeđa
- `assets/` — CSS, JavaScript i slike
- `data/` — strukturirani podaci
- `scripts/` — import, build i QA

Stari repozitorij ostaje izvor i sigurnosna kopija tijekom migracije.

## Uredničko načelo

PatriaSoul ne nabraja Hrvatsku. PatriaSoul istražuje, provjerava i pripovijeda njezine priče.
